# 사건 구역 배치 — 남겨둔 판단

구현·측정·게이트는 끝났다. 아래는 **내가 정할 수 없어서 남긴 것들**이다.
숫자는 전부 `scripts/layout/README.md`의 표에서 온 것이고, 다시 재려면

```bash
node --experimental-strip-types --import ./scripts/layout/register.mjs scripts/layout/measure.ts
```

---

## 1. 통과 조건을 글자 그대로는 못 채웠다 — 받아들일지 정해야 한다

계획서가 세운 조건은 "네 날 모두에서 `crowded`·`crossings`가 내려가야 한다"였다.

- `crowded`(글자 밑을 지나간 선): **여덟 칸 전부 하락.** 데스크톱 7·2·10·10 →
  0·1·6·8, 폰 18·21·31·30 → 2·0·6·9.
- `overlap`(겹친 라벨): 전부 0. 기존에 폰 07-31에 있던 1쌍도 사라졌다.
- `crossings`: **다섯 하락, 셋 상승.**
  - 데스크톱 08-01 `0 → 1`. 선이 34개뿐이라 예전 전역 시뮬이 우연히 교차 0을
    찾아냈던 날이고, 늘어난 1개는 다리다.
  - 데스크톱 08-03 `19 → 21`, 폰 08-03 `13 → 20`. 둘 다 `xIn`이 18이다.

**판단이 필요한 지점**: 남은 교차는 거의 전부 하루의 제일 큰 사건 *하나 안*에
있고(08-02는 16개 전부 `xIn`, `xBr`은 0), 서로 무관한 두 이야기의 선이 엇갈리는
일은 없어졌다. 나는 이걸 "설계가 틀렸다"가 아니라 "재는 자가 한 겹 거칠었다"로
읽었지만, 조건을 세운 것은 계획서이고 그 조건을 완화할지 말지는 내가 정할 일이
아니다.

되돌리려면 손댈 곳은 B단계(패킹)다. A단계와 선 잉크는 그대로 두고 패킹만 느슨한
전역 force로 바꾸면 중간 지점이 나온다.

## 2. 조밀 사건 하나를 더 펼 것인가

08-02의 전당대회는 13단어 27엣지다. 교차 16개가 여기서 나온다. 시도한 것:

- `LOCAL_SLACK` 1.8 / 2.5 / 3.5 / 5.0 훑음 → 3.5가 최선. 더 키워도 안 줄어든다.
- `untangle`(두 멤버의 자리를 맞바꿔 교차가 줄면 남기기) → 작은 사건에서는
  `xIn`을 1에서 0으로 내렸지만 **큰 사건에서는 하나도 못 줄였다.** 단쌍 교환은
  그 크기의 조밀 그래프에서 곧바로 지역 최적에 걸린다.

13노드 27엣지는 이론상 평면으로 그릴 수 있다(3n−6 = 33). 실제로 그러려면 평면성
판정 + 임베딩이 필요하고, 그건 이 작업의 범위를 훨씬 넘는다. **할지 말지는
판단이 필요하다** — 화면에서 제일 눈에 띄는 남은 흠이지만, 값이 크다.

## 3. 선 굵기·투명도 최종값

지금 값(`KeywordGraph.tsx`):

```
t = clamp01((npmi − 0.3) / 0.7)
strokeWidth   = 0.8 + 2.2·t     (이전 0.9 ~ 2.2)
strokeOpacity = 0.15 + 0.70·t   (이전 0.26 ~ 0.48)
```

계획서에 "**최종 숫자는 눈으로 보고 정한다**"고 적혀 있었다. 나는 네 날 ×
데스크톱·폰 스크린샷으로 확인했고 강약이 확실히 구별된다고 봤지만, "강한 건
진하게, 약한 건 옅게"를 고른 사람은 나가 있었다. **실물로 보고 세기를
조정할 여지를 남겨둔다.** 상수 네 개(`EDGE_WIDTH_MIN`, `EDGE_WIDTH_SPAN`,
`EDGE_OPACITY_MIN`, `EDGE_OPACITY_SPAN`)만 만지면 된다.

## 4. 작은 것 둘

- **07-31 데스크톱에서 `로보틱스—제미나이` 한 쌍이 자기 선반 한 줄을 통째로
  차지한다.** 선반 패킹이 넓이순이라 생기는 낭비고, 보기 흉하지는 않지만 세로를
  한 줄 버린다. 높이순 정렬로 바꾸면 촘촘해지는 대신 하루의 제일 큰 이야기가
  왼쪽 위를 못 잡을 수 있다.
- **데스크톱 08-01의 `lenMax`가 739로 남아 있다.** 그 날은 다리가 하나뿐이라
  `orderForPacking`이 순서를 바꿀 여지가 없다. 다른 날은 240·228·540이다.
